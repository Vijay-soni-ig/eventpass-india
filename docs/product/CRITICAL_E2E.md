# Critical End-to-End Scenarios

E2E-01 Exhibition: Organizer → event → venue/hall/stalls → publish → exhibitor → stall reservation → payment → confirmed booking.

E2E-02 Visitor ticket: discovery → registration → ticket selection → order → payment → verified ticket → QR.

E2E-03 Check-in: scanner auth → QR → server validation → check-in → duplicate rejection.

E2E-04 Lead: visitor interaction → lead → interaction → follow-up → exhibitor analytics.

E2E-05 Refund: eligible cancellation → refund request → authorization → provider/refund processing → reconciliation → availability update.

E2E-06 Tenant isolation: Organizer A attempts Organizer B event/stall/booking/payment/lead access → rejection and safe audit event.
